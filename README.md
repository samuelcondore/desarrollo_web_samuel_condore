# desarrollo_web_samuel_condore

Para llegar a los comentarios el camino a seguir es: Listado -> Click en alguna actividad para ver datos de miembro y sus actividades según lo indicado -> Click en una de las actividades del miembro

Todos los errores de validador de html que surgieron son debido a sintáxis de jinja y algunos encabezados que solo aparecen en una plantilla base.html de la cual todas las demás heredan.

El selector de intervalo de tiempo en la página de estadísticas es solo para el primer gráfico.

Todos los mensajes de error/éxito de formularios se despliegan con la función flash() y aparecen en el tope de la página.

Principales fuentes usadas:
  - w3schools.com (css, html)
  - highcharts.com (highcharts api)
  - developer.mozilla.org (js)
  - medium.com (js, html)
  - stackoverflow.com + reddit.com (preguntas varias y debugging)
